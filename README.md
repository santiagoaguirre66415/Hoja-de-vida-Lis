# Hoja de vida - Lis

Repositorio con la hoja de vida en formato HTML, CSS y JavaScript.

Archivos principales

- [index.html](index.html): página principal con la hoja de vida.

Cómo usar

1. Abrir [index.html](index.html) en tu navegador local.
2. Edita `index.html` para actualizar contenido visual o `styles.css` / `script.js` si existen.

Publicar

- Para publicar en GitHub Pages, activa GitHub Pages desde la rama `main` en la configuración del repositorio.

Notas

- Este repositorio contiene archivos estáticos; no requiere servidor para visualizar.
- Para cambios: `git add .`, `git commit -m "Actualiza hoja de vida"`, `git push`.

Si quieres que prepare un despliegue automático a GitHub Pages o un README más detallado, dime qué prefieres.
